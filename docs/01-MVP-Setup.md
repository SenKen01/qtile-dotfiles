# Отчет №1: Инициализация проекта и запуск MVP Qtile

## 🎯 Цель этапа
Создать чистую, отказоустойчивую базовую конфигурацию оконного менеджера **Qtile** (MVP), организовать архитектуру проекта по стандартам разработки (Git Flow) и связать локальную директорию с удаленным репозиторием на GitHub.

---

## 📂 Архитектура проекта
Рабочая директория `~/.config/qtile` преобразована в локальный Git-репозиторий со следующей структурой:

```text
~/.config/qtile/
├── .git/               # Системные файлы Git
├── .gitignore          # Исключения (кэш Python, бэкапы, настройки рабочей области)
├── README.md           # Главная страница репозитория для GitHub
├── config.py           # Основной файл конфигурации Qtile (MVP)
└── docs/               # Документация и отчеты по разработке (связано с Obsidian)
    └── 01-MVP-Setup.md # Текущий отчет
```

---

## 🛠 Выполненные работы

### 1. Подготовка базовой конфигурации (MVP)
* Создана директория `~/.config/qtile` и настроено резервное копирование (`*.backup` добавлены в `.gitignore`).
* Проверен синтаксис базового файла `config.py` с помощью интерпретатора Python (`python3 ~/.config/qtile/config.py`) — ошибок не выявлено.

### 2. Настройка Git и модели ветвления
Инициализирован репозиторий и настроена двухветочная модель разработки:
* **`main`** — стабильная ветка (хранит только проверенный, рабочий конфиг).
* **`dev`** — ветка разработки (сюда будут вливаться `feature/*` ветки перед релизом в `main`).

### 3. Настройка SSH-аутентификации и GitHub
* При первой попытке отправки кода (`git push`) возникла ошибка доступа: `Permission denied (publickey)`.
* Сгенерирована пара криптографических ключей **ED25519** (`ssh-keygen -t ed25519`).
* Публичный ключ добавлен в настройки аккаунта GitHub (`SenKen01`).
* Проверено соединение через `ssh -T git@github.com` (успешная аутентификация).
* Создан удаленный репозиторий `git@github.com:SenKen01/qtile-dotfiles.git` и загружены обе ветки (`main` и `dev`).

## 💻 Использованные команды (Лог)
```bash
# Инициализация и первый коммит в main
git init
git branch -M main
git add config.py .gitignore README.md docs/
git commit -m "feat: initial MVP configuration setup"

# Создание ветки разработки
git checkout -b dev

# Привязка к GitHub и отправка веток
git remote add origin git@github.com:SenKen01/qtile-dotfiles.git
git push -u origin main
git push -u origin dev
```
