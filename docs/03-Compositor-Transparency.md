# Отчет №3: Настройка композитора Picom

## 🎯 Цель этапа
Внедрить в систему композитор `picom` для обеспечения полупрозрачности всех окон (эффект матового стекла), размытия фона (`blur`) и скругления углов (`10px`). Настроить автоматический запуск при старте сессии Qtile.

---

## 🛠 Выполненные работы

### 1. Установка зависимостей (Debian 13)
Установлены системные пакеты для композитинга, обоев и будущей работы с изображениями в Python:
* `picom`, `feh`, `python3-pil`, `python3-requests`, `python3-bs4`.

### 2. Конфигурация и автозапуск
* Создан конфиг `~/.config/qtile/scripts/picom.conf` (настроена прозрачность `0.88` для активного окна и `0.78` для неактивного, исключен полноэкранный режим).
* Создан исполняемый скрипт `~/.config/qtile/scripts/autostart.sh`.
* В `core/hooks.py` подключен декоратор `@hook.subscribe.startup_once`, вызывающий `autostart.sh` один раз при входе в систему.

### 3. Исправление бага (Hotfix)
* **Проблема:** После первичной настройки скругление углов сбросилось из-за несовместимости параметра `dual_kawase` с версией `picom` в Debian 13 без экспериментальных флагов.
* **Решение:** Метод размытия переведен на стабильный `gaussian` (`blur-method = "gaussian"`), после чего `picom` заработал без сбоев.
